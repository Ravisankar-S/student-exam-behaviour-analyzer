# student-exam-behaviour-analyzer
mini-project semester 6 (dev in progress)

## Data
- Full training datasets are not stored in the repo. Place them under `backend/train_data/` locally.
- A small sample CSV is provided at `data/sample/behaviour_training_sample.csv` for quick testing.
- Required columns for training:
	- `avg_time`, `time_variance`, `revision_count`, `wr_ratio`, `rw_ratio`, `navigation_count`, `rte_score`, `accuracy`, `behavioural_label`
